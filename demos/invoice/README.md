# 請求書をボタン1つで作り、入金の照らし合わせまで自動にする

明細を入れてボタンを押すと、インボイス（適格請求書）の項目がそろった請求書のPDFと、PDFを付けたGmailの下書きができます。
明細は、取引先を選ぶだけで請求日と支払期限が入ります。毎月同じ請求は自動で明細が入ります。入金は、ネットバンクのCSVを置いてボタンを押すと、合う請求書が「入金済み」になります。

## Before / After

| | Before | After |
|---|---|---|
| 請求書を作る | Excelのひな形に、取引先・品目・金額を1枚ずつ手で打ち、PDFにして保存 | 明細を入れてボタンを押すだけ。取引先と請求日ごとに1枚にまとめ、PDFを保存する |
| 消費税・請求日・支払期限 | 税率ごとの計算と、取引先ごとの請求日・支払期限を手で計算 | 税率ごとに合計して消費税を計算する。取引先を選ぶと、請求日（次の締め日）と支払期限が自動で入る。契約で違うときは、明細で日付を書き換えるだけ |
| メールで送る | メールを書き、宛名・金額・期限を写し、PDFを添付 | 宛名・金額・期限の入った、PDF付きの下書きができる。確かめて送るだけ |
| 毎月同じ請求 | 毎月、同じ明細を打ち直す | 毎月1日に明細が自動で入る |
| 入金の確認 | ネットバンクの入金を見て、どの請求書の支払いかを1件ずつ照らし合わせる | CSVを置いてボタンを押すと、合うものは自動で「入金済み」。迷うものだけ候補つきで黄色に残る |
| 請求書の訂正 | 古いPDFを上書きして、どれが正しいか分からなくなる | 元の請求書を「取消」にして理由を残し、新しい番号の訂正版を作る |

## 毎日の使い方

### 請求書を作る

1. 各担当者が、「明細」シートに請求する内容を1行に1品目ずつ入れます
   - 取引先・請求日・支払期限が同じ行が、1枚の請求書になります
   - 取引先を選ぶと、「請求日」に次に来る締め日、「支払期限」に取引先の条件（締め日・支払日）から決まる日が自動で入ります
   - 案件ですぐ請求する・着手金など、契約で違うときは、日付を書き換えてください。書き換えた日付は、ほかを変えてもそのままです（請求日を書き換えると、支払期限はその日から入れ直します）。空にすると、自動の日付に戻ります
   - 単価は税抜です。数量が空なら1、税率が空なら10%にします。値引きは単価をマイナスにします
   - 取引先は、「取引先」シートにある取引先から選びます
2. 「操作」シートの「請求書を作る」を押します
   - 作る枚数と合計の金額が出るので、「OK」を押します
   - 請求書のPDFが「請求書を保存するフォルダ」にでき、「請求書一覧」に1行ずつ増えます。明細の「請求書番号」に番号が入ります
   - 番号は「請求日の年月-その月の通し番号」です（例：2026-10-001）
3. Gmailの「下書き」を開き、宛先・本文・添付のPDFを確かめてから送ります
   - **メールは自動では送りません**。送ってよいものだけを送ってください
   - 下書きは、ボタンを押した人のGmailにできます。取引先の「CC」に書いた人は、CCに入ります

請求書のPDFには、インボイスの項目（登録番号、税率ごとの合計と消費税、軽減税率の印）のほか、取引の期間を載せます。請求日が取引先の締め日なら「対象期間」（前の締め日の翌日〜締め日。例：10/01〜10/31）、それ以外の日なら「取引日」（請求日）です。

### 入金を確かめる

1. ネットバンクから入金明細のCSVをダウンロードし、「入金明細のCSVを置くフォルダ」に入れます
   - 前に入れたCSVと期間が重なっていても大丈夫です。同じ入金を2回取り込むことはありません
2. 「操作」シートの「入金を取り込む」を押します
   - 入金が「入金」シートに並びます（出金の行は読みません）
   - 振込名義と金額が合う請求書は、自動で「入金済み」になります。2枚分をまとめた入金も、合計が合えば自動です
   - 日付や金額を読めない行・列の名前が合わないCSVがあると、画面にファイル名と行が出ます。ほかの入金はそのまま取り込みます
3. 「入金」シートの黄色い行を確かめます
   - 「確認事項」に、迷った理由と候補が書いてあります（振込手数料を引いた入金、名義が取引先と違う、など）
   - 「請求書番号」が合っていれば（違えば直して）、「確認」にチェックを入れると、その請求書が「入金済み」になります
   - 2枚分なら、番号をカンマで区切って入れます
   - 金額に差があっても（一部だけの入金など）、チェックを入れれば入金済みになります。差は黄色のまま「確認事項」に残るので、残りの請求や返金を確かめたら、文を消してください
   - 請求書の支払いでない入金（利息など）は、「請求書番号」を空にしてチェックを入れます
   - **番号を間違えてチェックしたときは、チェックを外します**。請求書は未入金に戻り、行は確認待ちに戻ります

現金で受け取ったときなど、CSVにない入金は、「請求書一覧」の「状態」を「入金済み」にします（入金日と入金額が空なら、今日の日付と請求額が入ります）。「未入金」に戻すと、入金日と入金額は消え、その請求書で反映した「入金」の行は確認待ちに戻ります。

### 請求書を直す（取消・訂正）

1. 「請求書一覧」で、直したい請求書の行（どのセルでも）を選びます
2. メニュー「請求書 → 選んだ請求書を取消す」を押し、取消す理由を書いて「OK」を押します
   - 一覧の「状態」が「取消」になり、「取消・訂正」に理由が残ります
   - PDFは消さず、名前の先頭に「【取消】」が付きます。Gmailの下書きが残っていれば消します
3. 「明細を作り直しますか？」と出るので、選びます
   - 「OK」（金額の誤りなど）：その請求書の明細は、番号が消えて黄色になります。明細を直して「請求書を作る」を押すと、新しい番号の請求書（訂正版）ができ、PDFに「（元の番号）の訂正版です」と書かれます
   - 「いいえ」（取引がなくなったなど）：明細の番号に「（取消）」が付き、もう請求書は作りません
   - 入金済みの請求書は取消せません。先に「状態」を「未入金」に戻してください

### 見かた

| 色・表示 | 意味 |
|---|---|
| 行全体が赤 | 直す必要がある行。「確認事項」のとおりに直して、もう一度ボタンを押す |
| 行全体が黄色 | 確かめてほしい行。「確認事項」を読んで、確かめたら文を消すと色が戻る（「入金」シートは「確認」にチェック） |
| 「状態」のセルが薄い赤 | 未入金 |
| 「状態」のセルが緑 | 入金済み |
| 薄い青のセル | 入力・選択するところ |
| 「明細」の上の赤い帯 | 自動の処理で問題が起きた。管理者にもメールで知らせています |

各シートの見出しの行は、ツールが使います。消そうとすると警告が出ます。

## 初めて使うとき

1. 「設定」シートに、自社の情報（会社名・登録番号・振込先）と、2つのフォルダのURLを貼る
   - フォルダは、Googleドライブで今使っているものです。フォルダを開いたときの、上のアドレス（URL）を貼ります
   - 押す人は、どちらのフォルダにも**編集者**として共有されている必要があります
2. 「取引先」シートに、取引先を登録する
   - 「締め日」「支払月」「支払日」は必須です（月末締め翌月末払いなら 末日・翌月・末日）
   - 「振込名義（カナ）」は、通帳に出る名前です（例：カ)サンプルシヨウジ）。空だと、入金を名義で照らし合わせられません
   - 毎月同じ請求をする取引先は、「毎月の請求」シートにも書きます。品目に `{月}` と書くと、「10月」のように月が入ります
3. 「操作」シートの「請求書を作る」を押す
   - 初めてのときは「承認が必要です」と出ます。「続行」→ 自分のアカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら、「詳細」→「（プロジェクト名）に移動」を押す
   - 「許可」を押す。終わったら、もう一度「請求書を作る」を押す
4. 管理者が、メニュー「請求書 → 自動の処理を始める（管理者）」を押す（「管理者向け」を参照）

ボタンはパソコンのブラウザで使ってください（スマートフォンのアプリでは動きません）。

## うまくいかないとき

| 困っていること | すること |
|---|---|
| 「明細」の行が赤い | 「確認事項」のとおりに直して、もう一度「請求書を作る」を押す |
| 「明細」の行が黄色く、「同じ請求書の明細に直すところがある」と出る | 同じ取引先・同じ請求日の、赤い行を直す。直すと一緒に作られます |
| 「取引先」が選べない | 先に「取引先」シートに足す。足すと選べるようになります |
| 「「設定」シートを直して」と出る | 出ている項目を書く・直す |
| 「タイムゾーンが〜になっていて、日付が1日ずれてしまいます」と出る | 「ファイル → 設定」の「タイムゾーン」を「(GMT+09:00) 東京」にして、もう一度押す |
| 結果に「残り ○枚」と出た | もう一度「請求書を作る」を押す（続きから作ります） |
| 一覧の行が黄色く「下書きを作っていません」と出る | 取引先のメールアドレスがない・下書きを作れなかった。PDFのリンクを開いて、ほかの方法で送る |
| 「ほかの人が請求書を作っているか、入金を取り込んでいます」と出る | 少し待ってから、もう一度押す |
| 請求書の金額を間違えた | 「請求書を直す（取消・訂正）」の手順で直す。明細を直すだけでは、作ったPDFは変わりません |
| 下書きを送ったあとで取消した | 取引先に、取消と訂正版を送る旨を連絡する |
| 入金が黄色で「振込名義が取引先と合いません」と出る | 候補が合っていれば「確認」にチェック。次から自動にするには、「取引先」の「振込名義（カナ）」を通帳の名前に直す |
| 「確認」にチェックしたら外れて、理由が出た | 「確認事項」のとおりに番号を直して、もう一度チェックする。「ほかの処理の途中」と出たときは、少し待ってからチェックする |
| 違う請求書で入金済みにしてしまった | 「入金」のその行の「確認」のチェックを外す（請求書は未入金に戻る）。正しい番号を入れて、もう一度チェックする |
| 「読めなかったものがあります」と出て、「列が見つかりません」とある | 「設定」の「CSVの入金日の列」など3つを、CSVの1行目（見出し）の名前に合わせる。別の口座のCSVなら、フォルダから外す |
| 「読めなかったものがあります」と出て、「日付か金額を読めませんでした」とある | その入金は「請求書一覧」で手で「入金済み」にする。毎回出るときは、製作者に連絡する（銀行のCSVの形に合わせます） |
| 「入金」の黄色い行に「反映の途中で止まりました」とある | もう一度「入金を取り込む」を押す（続きを反映します） |
| 「明細」の上に赤い帯が出ている | 管理者に連絡する（管理者にはメールでも届いています） |
| 「[E〜]」で始まるエラーが出た | 番号を添えて管理者に連絡する |

## 管理者向け

### 導入のしかた

1. 「初めて使うとき」の1〜3をする
2. 「設定」の「管理者のメールアドレス」を書く
3. メニュー「請求書 → 自動の処理を始める（管理者）」を押す
   - 今月の毎月の明細を入れるかを聞かれます。月の途中で始めて、今月分をもう手で入れたときは「いいえ」
   - 自動の処理のエラーのメールは、**ここで押した人のGmailから管理者に送られます**。担当者が替わっても残る、会社の共用アカウントで押してください
4. 使う人に、スプレッドシートと2つのフォルダを「編集者」として共有する

### 自動の処理を止める・再開する

- メニュー「請求書 → 自動の処理を止める（管理者）」で止まります。止めている間は、毎月の明細が入りません
- 「自動の処理を始める（管理者）」で再開します。その月の毎月の明細をまだ入れていなければ、入れるかどうかを聞きます
- ほかの人が動かしているときに押すと、「送信元を替えますか？」と出ます。「OK」でその人のGmailからエラーのメールを送るようになります

### 自動で動いているもの

| いつ | 何をするか |
|---|---|
| 毎朝8時ごろ | その月の毎月の明細をまだ入れていなければ、「明細」に入れる（請求日は、取引先ごとのその月の締め日）。1日に動けなかったときは、次に動いたときに入れる |
| 毎朝8時ごろ・「請求書を作る」を押したとき | 前に入れられなかった「毎月の請求」の行（赤い行）が直っていれば、その月の明細として入れる |

自動の処理で起きたエラーは、管理者にメールで届き、「明細」の上に赤い帯でも出ます。同じエラーのメールは1日1通までです。次にうまく動くと、帯は消えます。

### エラー番号の一覧

| 番号 | 内容 | 直し方 |
|---|---|---|
| E21 | 請求書を保存するフォルダを開けない | 「設定」のURLが正しいか、押した人がフォルダの編集者か確かめる |
| E22 | 入金明細のCSVを置くフォルダを開けない | 同じく、URLと共有を確かめる |
| E23 | 請求書のPDFを保存できない | 押した人がフォルダの編集者か、Googleドライブの容量に空きがあるかを確かめる。止まる前に作った請求書は一覧にあります |
| E24 | シートの見出しの行が見つからない | 見出しの名前（「品目」「請求書番号」など）を消すか書き換えると出ます。「編集 → 元に戻す」か「ファイル → 変更履歴」で戻す |
| E27 | 「設定」「毎月の請求」の値が正しくない（自動の処理で見つけた） | メールと帯に出ている項目を直す。「毎月の請求」の赤い行は、直すと次の朝（または「請求書を作る」を押したとき）に、その月の明細として入る |
| E28 | スプレッドシートのタイムゾーンが日本時間でない（自動の処理で見つけた） | 「ファイル → 設定」の「タイムゾーン」を「(GMT+09:00) 東京」にする。日本時間でないと、日付が1日ずれます |
| E99 | 想定外のエラー | 製作者に連絡する（Apps Script の「実行数」のログを添えて） |

### 変えられる設定

すべて「設定」シートにあります。

| 設定 | 内容 |
|---|---|
| 会社名・住所・電話番号・登録番号・振込先・請求書の備考 | 請求書に載せる自社の情報 |
| 請求書を保存するフォルダ・入金明細のCSVを置くフォルダ | GoogleドライブのフォルダのURL |
| CSVの入金日の列・振込名義の列・入金額の列 | 銀行のCSVの1行目（見出し）の名前。銀行を替えたら合わせる |
| 振込手数料として見る差（円） | 入金が請求額よりこの金額まで少ないとき、手数料を引いた入金の候補にする（初めは880円） |
| 消費税の端数 | 切り捨て・四捨五入・切り上げ（初めは切り捨て） |
| 管理者のメールアドレス | 自動の処理（毎月の明細）のエラーが届く |
| 下書きの件名・下書きの本文 | `{宛名}` `{会社名}` `{請求月}` `{請求書番号}` `{請求額}` `{支払期限}` `{振込先}` `{取引先}` が使える |

### 中で覚えていること

月ごとの最後の請求書番号、読み終えたCSV、自動の処理を動かすアカウント、毎月の明細を入れた月は、Apps Script の「プロジェクトの設定 → スクリプト プロパティ」に残しています。書き換えないでください。
「明細」「請求書一覧」「入金」には、ツールが使う「管理用」の列が隠してあります（取消した請求書とのつながり・毎月の請求から入れた印・自動で入れた請求日と支払期限、PDF・下書きの場所、同じ入金を見分ける印）。消さないでください。

### 必要な権限

初めて押したときに、次の権限の許可を求められます。

- スプレッドシートの読み書き（このスプレッドシートだけ）
- Googleドライブ（請求書のPDFを保存する・名前を変える、入金明細のCSVを読む）
- Gmail（請求書の下書きを作る・取消のときに消す）
- メールの送信（自動の処理のエラーを管理者に知らせる）
- 自動の処理（毎朝のトリガー）

## 使った技術

- Google Apps Script（ボタン・メニュー、時間のトリガー、HTML から PDF を作る（Utilities.newBlob → getAs）、DriveApp でPDFの保存とCSVの読み取り、GmailApp で下書き、MailApp で管理者へのエラーの知らせ）
- スプレッドシートの入力規則（取引先・税率・締め日のプルダウン、日付・数字・メールアドレスの形、チェックボックス）、条件付き書式（状態の色）、保護（見出しの行を消すと警告）
- LockService（2回押されても同じ明細で2枚作らない、入金の反映を1件ずつ）
- 手元のテスト：`node --test tests/*.test.js`（GASの部品を偽物に差し替えて、計算・照らし合わせ・ボタンの流れを確かめる）
